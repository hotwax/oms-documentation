# Sales Orders

## Scope

Sales order integration was discussed only as context. Phase 1 does not change ThirdLove’s existing Shopify ↔ NetSuite order flow.

## Current Flow (as stated in transcripts)

- Shopify orders sync to NetSuite.
- Fulfillment updates sync back to Shopify.

## Future Considerations Raised in Discovery

If ThirdLove adds BOPIS or ship-from-store later, the team highlighted the need to confirm:

- **Where allocation/reservation happens:** Shopify vs NetSuite vs HotWax
- **Inventory timeliness:** how quickly inventory updates propagate so customers are not promised unavailable inventory
- **Store execution:** how stores are notified, what is reserved, and how exceptions are handled

These topics should be revisited before expanding scope beyond store inventory management.
