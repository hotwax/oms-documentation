# 2026-01 Release Notes

This month’s release focuses on strengthening the connection between HotWax and NetSuite, improving data accuracy and reducing manual work. We’ve made significant updates to transfer order processing, shipment synchronization, and inventory alignment to help you manage omnichannel operations with greater confidence.

## NetSuite Connector
### Transfer Orders
Transfer order processing between HotWax and NetSuite now includes automated data synchronization for items. The system generates feeds to send transfer order details to NetSuite, reconcile completed items with receipts, and create inventory adjustments for discrepancies. These updates improve data accuracy and reduce manual effort when managing transfers between systems.
*Sources: [hotwax/mantle-netsuite-connector#62](https://github.com/hotwax/mantle-netsuite-connector/pull/62), [hotwax/mantle-netsuite-connector#177](https://github.com/hotwax/mantle-netsuite-connector/pull/177), [hotwax/mantle-netsuite-connector#175](https://github.com/hotwax/mantle-netsuite-connector/pull/175), [hotwax/mantle-netsuite-connector#171](https://github.com/hotwax/mantle-netsuite-connector/pull/171), [hotwax/mantle-netsuite-connector#189](https://github.com/hotwax/mantle-netsuite-connector/pull/189)*

### Shipment Synchronization
HotWax now prevents unnecessary shipment data from synchronizing to NetSuite. The system skips shipment creation for items already completed in our OMS and excludes shipments lacking a NetSuite order sync or external shipment reference. This ensures cleaner data transfer and reduces manual reconciliation efforts in NetSuite.
*Sources: [hotwax/mantle-netsuite-connector#192](https://github.com/hotwax/mantle-netsuite-connector/pull/192), [hotwax/mantle-netsuite-connector#182](https://github.com/hotwax/mantle-netsuite-connector/pull/182), [hotwax/mantle-netsuite-connector#190](https://github.com/hotwax/mantle-netsuite-connector/pull/190)*

### Reconciliation Feed
The reconciliation feed now supports filtering transfer orders by creation date. This allows you to retrieve specific reconciliation details based on when orders were placed. Additionally, the system prevents generation of empty reconciliation files, ensuring feeds only contain relevant data for review.
*Sources: [hotwax/mantle-netsuite-connector#194](https://github.com/hotwax/mantle-netsuite-connector/pull/194), [hotwax/mantle-netsuite-connector#193](https://github.com/hotwax/mantle-netsuite-connector/pull/193)*

### Inventory Synchronization
You now have greater control over inventory alignment with NetSuite. We added a reset-based synchronization flow that identifies and exports only inventory variances between systems. This process uses configurable quantity types (QOH or ATP) and creates auditable records of all adjustments made in NetSuite.
*Sources: [hotwax/mantle-netsuite-connector#173](https://github.com/hotwax/mantle-netsuite-connector/pull/173)*

## Order Management
### Order Processing
POS order history now includes all relevant transactions. Previously, history creation was skipped for some POS orders within batches containing partial payments. We updated the system to accurately record order history for all POS orders, excluding only intentionally skipped partial payments. Additionally, the system more reliably identifies mix-cart orders by verifying distinct shipment methods at the item level.
*Sources: [hotwax/mantle-netsuite-connector#187](https://github.com/hotwax/mantle-netsuite-connector/pull/187), [hotwax/mantle-netsuite-connector#170](https://github.com/hotwax/mantle-netsuite-connector/pull/170)*

## System & Core Updates
### Data Model Centralization
Previously, the `view-entity` definition lived within the NetSuite Connector. We relocated this definition to the `ofbiz-oms-udm` repository to centralize all order management data models. This change improves consistency and simplifies future updates to order views across connected systems.
*Sources: [hotwax/mantle-netsuite-connector#191](https://github.com/hotwax/mantle-netsuite-connector/pull/191)*
