
# Maarg

Maarg is the modern integration and middleware platform used by HotWax Commerce. It is built on the open-source Moqui framework and works as the central data hub that connects the core Order Management System (OMS) with external systems such as Shopify, NetSuite, and warehouse management tools. Maarg handles the complex flow of orders, manages large-scale synchronization of inventory and product data, and automates high-volume background tasks using scheduled jobs, data entities, and asynchronous system messages.
