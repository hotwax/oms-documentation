# Manage message types

Open `System messages` > `Message types` to review the message definitions used by integrations.

## Find a message type

Search by message type identifier, description, or another displayed value. Select a result to open its details and related messages.

## Review a message type

Confirm the identifier and configuration fields before you compare related messages. Use the related-message list to investigate current traffic for that type.

## Create or edit a message type

The create, edit, save, and delete controls require `COMMON_ADMIN`.

1. Select the create action or open an existing type.
2. Enter the required fields.
3. Review the identifier before the first save. An existing identifier can be read-only.
4. Select `Save`.
5. Reopen the type and confirm the stored values.

Delete a message type only after you confirm that integrations and existing messages no longer depend on it.

## Review related messages

Use search, status filters, and pagination to inspect messages associated with the type. Select a message to open its detail.

See [Trace a system message](message-details.md).
