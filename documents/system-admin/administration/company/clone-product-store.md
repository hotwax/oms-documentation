# Clone Product Store settings

Clone settings when a target Product Store should use approved configuration from an existing source Product Store.

Cloning overwrites the selected categories on the target Product Store. The clone page provides no undo action.

## Clone settings

1. Open the **Company App**.
2. Go to `Product Store`.
3. Click `Clone store settings`.
4. Select the `Source Product Store`.
5. Select the `Target Product Store`.
6. Select the categories to copy:
   * Order configurations
   * Brokering rules
   * Fulfillment settings
   * Inventory settings
   * Product configurations
   * Order edit permissions
7. Review the overwrite warning.
8. Click `Clone settings`.
9. Confirm the action.
10. Open the target Product Store and verify each copied category.

Choose different source and target Product Stores.

## Before cloning

Confirm these points:

* The source settings are approved for the target brand or storefront.
* Integration-specific identifiers are valid for the target.
* The target values can be replaced.
* A tester is available to validate the affected order and inventory workflows.
