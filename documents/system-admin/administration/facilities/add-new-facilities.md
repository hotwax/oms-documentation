# Add a facility

Create a facility for every physical or operational location that holds inventory, fulfills orders, receives goods, or supports pickup.

## Create the facility

1. Open the **Company App**.
2. Go to `Facilities` > `Find`.
3. Click the create button.
4. Select the facility type, such as store or warehouse.
5. Enter the facility name.
6. Review the generated internal ID and enter an external ID when required.
7. Click `Create Facility`.

## Add the address

1. Enter the street address, city, country, state, and postal code.
2. Enter latitude and longitude, or use the generate action after the address is complete.
3. Save the address.

Accurate coordinates support distance-based routing and pickup-location search.

## Configure the facility

Review these settings:

* `Product Store`: Associates the facility with the brands it supports
* `Sell inventory online`: Adds facility inventory to an approved sales-channel group
* `Allow pickup`: Makes the facility eligible for pickup workflows
* `Use native fulfillment app`: Indicates whether the facility uses HotWax Commerce fulfillment
* `Generate shipping labels`: Enables supported label generation
* `Days to ship`: Records the facility lead time

Create a facility login only when the facility uses an approved shared-login workflow.

Click `Save Configurations` when the required values are complete. You can return to [Manage facility details](manage-facility-details.md) to add remaining configuration.
