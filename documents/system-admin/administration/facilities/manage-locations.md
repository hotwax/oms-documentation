# Manage internal locations

Internal locations describe where inventory is stored, received, staged, or picked inside a facility.

## Add a location

1. Open the **Company App**.
2. Go to `Facilities` > `Find`.
3. Select the facility.
4. Open the `Locations` tab.
5. Click `Internal Locations`.
6. Select the location type:
   * `Bulk`
   * `Pick/Primary`
   * `Receiving Bay`
   * `Staging`
7. Enter the applicable area, aisle, section, level, and sequence.
8. Save the location.

Use sequence to represent the approved pick order inside the facility.

## Edit a location

1. Open the location overflow menu.
2. Click `Edit Location`.
3. Update the fields.
4. Save the changes.

## Remove a location

1. Confirm that the location is no longer used by an active inventory workflow.
2. Open the location overflow menu.
3. Click `Remove Location`.
4. Confirm the removal.
