# Find customers

Use `Find customers` to locate a customer record and open its details.

## Search customers

Enter any of the following values:

* Customer name
* Party ID
* Email address
* Phone number

The list refreshes automatically after you type. This page does not provide additional filter controls.

## Read the results

Each customer row shows:

* Party ID
* Full name, or the party ID when no name is available
* Email, or `No email`
* Phone, or `No phone`

Select a row to open the customer detail page.

## Result states

The header shows the loaded count and total matching customers. Results load in groups of 50 as you scroll.

* A progress bar means the search is loading.
* `Customer search failed` means the request failed.
* `No matching customers` means the request completed but no customer matched the search.

Change the search text when no records match.
