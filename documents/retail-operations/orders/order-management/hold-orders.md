# Hold

Use `Hold` for open order tasks outside the dedicated substitute, bad-address, and fraud workflows.

## Search, filter, and sort

Search by order name. Available filters are:

* `Sales channel`
* `Order date from`
* `Order date through`
* `Task created from`
* `Task created through`
* `Facility`
* `Shipping method`

Sort by task date, order date, or order total. The default is oldest task first.

The Funnel can also open this page filtered to a task purpose.

## Review a task

Each card shows:

* Order and customer context
* Order total and task-created date
* Task name and purpose
* Estimated completion date, when available
* Notes
* Assignee and reporter
* `Resolution comment`

Use `View order` when you need the complete order record.

## Resolve a task

Enter a resolution comment when needed, then select `Resolve task`. Confirm before completing the task.

To resolve several tasks:

1. Select `Select`.
2. Choose the task cards.
3. Select `Resolve`.
4. Confirm the selected task count.

Each card's resolution comment is included when the selected tasks are completed.

## Page states

The page distinguishes first-load progress, a refresh over existing cards, retryable errors, filtered empty results, and an unfiltered empty queue. If you have task-creation permission, the unfiltered empty state links to `Find order` so you can create a task from an order.
