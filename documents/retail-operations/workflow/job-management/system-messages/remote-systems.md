# Manage remote systems

Open `System messages` > `Remote systems` to review connected-system definitions used by system messages.

## Find a remote system

Search by remote-system identifier, description, or another displayed value. Select a result to open its details and related messages.

## Create or edit a remote system

The create, edit, save, and delete controls require `COMMON_ADMIN`.

1. Select the create action or open an existing remote system.
2. Enter the required connection and identification fields.
3. Review the identifier before the first save. An existing identifier can be read-only.
4. Enter secrets only through the protected form fields.
5. Select `Save`.
6. Reopen the remote system and confirm its non-secret values.

Never copy a secret from this page into documentation, chat, an issue, or a screenshot.

Delete a remote system only after you confirm that message types, integrations, and existing messages no longer depend on it.

## Review related messages

Use search, status filters, and pagination to inspect messages associated with the remote system. Select a message to open its detail.

See [Trace a system message](message-details.md).
