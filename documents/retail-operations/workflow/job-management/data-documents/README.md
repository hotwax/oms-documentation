# Use data documents

Open `Data documents` > `Documents` to create reusable exports from HotWax Commerce data.

A data document defines a primary entity, selected fields, related fields, and conditions. You can preview the result before you export it.

## Choose a task

- [Build a data document](build-data-document.md)
- [Preview, export, and schedule a document](preview-export-schedule.md)
- [Review data document exports](export-history.md)

## Find a document

Use the catalog search and available entity or feed filters to find a document. Select a document to open its Graph Builder.

Use the create action when you need a new document.

## Understand the builder

The Graph Builder organizes work into these segments:

- `Issues`
- `Fields`
- `Conditions`
- `Preview`
- `Usage`
- `Recent Exports`

Resolve issues before you rely on a preview or export.

## Keep the definition focused

Add only the fields and relationships needed by the consumer. A focused document is easier to validate and less likely to expose unnecessary data.

The current app does not include Data Document Feed pages. Use only the document and export workflows described here.
