# Transfer Discrepancies

Use the `Discrepancies` tab to review transfer issues that need follow-up.

## Filter discrepancies
Use the left panel to narrow the list by:

- `Discrepancy Type`
- `Origin`
- `Destination`

Available discrepancy types:

- `Over`
- `Under`
- `Mis-shipped`

## Review discrepancy records
Each record shows:

- Transfer order name or order ID
- Product
- Origin facility
- Destination facility
- Transfer date
- Variance quantity

## Open the transfer order
Select any discrepancy record to open the related `Transfer order details` page.
