# Troubleshoot fulfillment

Confirm the selected facility and order status before changing an order. Use the guide that matches the problem.

| Problem | What to check |
| --- | --- |
| A user can open Launchpad but cannot fulfill orders | Check facility assignments in [Unable to Login](unable-to-login.md) and permissions in [Troubleshoot application access](../../../system-admin/administration/users/troubleshooting/application-access-issue.md). |
| An order is missing from the fulfillment queue | Use [Order Lookup](../order-lookup.md) to review the order's status, facility, and items. Then check the corresponding Open, In Progress, or Completed page. |
| A shipping label cannot be generated | Review the prerequisites and generation steps in [Shipping Label Generations](../shipping-label-generation.md). |
| An item cannot be fulfilled | Review [Rejection](../rejection.md), including the reason and the items affected, before confirming the action. |
| The interface uses the wrong language | Follow [Change Language](change-language.md). |

After correcting the cause, verify the affected order or shipment. Keep the order ID, shipment ID, facility, and exact error together when recording an unresolved issue.
