# Products

HotWax Commerce requires accurate product data to download orders, route fulfillment, track inventory, and report on catalog activity. The current Shopify product sync experience centers on the Company app product sync console and the Shopify bulk operation flow.

Use these guides to understand product sync:

1. **Product sync from Shopify:** Understand the current import process and what product data HotWax imports.
2. **First-time product sync setup:** Confirm product store, identifier, and catalog readiness before the first import.
3. **Product sync console:** Monitor returning-user sync status, progress, history, and errors.
4. **Updating product details:** Understand how Shopify changes update HotWax product records.
5. **Deleting products:** Understand how Shopify delete events remove shop links while preserving historical records.
