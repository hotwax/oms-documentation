# Products

`HotWax Commerce` requires accurate product data to track inventory changes and maintain near real-time inventory counts on Shopify. It also supports order downloads and speeds up the fulfillment process. For precise synchronization of products from Shopify to `HotWax Commerce`, we handle four key scenarios:

1. **Initial product download:** Downloading existing products from the merchant's Shopify store keeps the `HotWax Commerce` product catalog up to date.
2. **Import newly added products:** Reflecting new products or variants added by merchants on Shopify in the `HotWax Commerce` product catalog.
3. **Update product details:** Synchronizing `HotWax Commerce` with the Shopify store as product information changes.
4. **Delete existing products:** Maintaining data integrity by removing products from `HotWax Commerce` when they are deleted from the Shopify store.
