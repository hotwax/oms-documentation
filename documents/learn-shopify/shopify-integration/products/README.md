# Products

HotWax Commerce imports Shopify products and variants to support order processing and inventory mapping. The product integration covers:

1. [Product download](download-products.md) for the initial catalog and recurring updates
2. [Product detail updates](update-product-details.md) for supported fields and comparison behavior
3. [Product deletions](delete-products.md) for removed variants and deleted parent products
4. [Product sync monitoring](product-sync-console.md) for requests, exports, imports, and recovery

Product import establishes the catalog and Shopify inventory item links. [Import inventory from Shopify](../inventory/import-inventory-from-shopify.md) separately to seed physical stock during onboarding.
